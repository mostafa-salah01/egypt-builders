# موقع شركة بناة مصر للإنشاءات والمقاولات (Egypt Builders – EB)
> موقع إلكتروني ثابت (Static Website) احترافي مصمم وفق أعلى معايير الويب الحديثة (HTML5 + CSS3 + Vanilla JavaScript) مخصص للنشر المباشر والمجاني على **GitHub Pages**.

---

## 📁 1) هيكل الملفات والمجلدات

```text
├── index.html            ← الصفحة الرئيسية (الهيرو، الرؤية، الخدمات، المشروعات، آراء العملاء)
├── about.html            ← صفحة من نحن (قصة الشركة، الرؤية والرسالة والقيم، فريق العمل)
├── services.html         ← صفحة خدماتنا (تفاصيل الخدمات الست والتقنيات الإنشائية)
├── projects.html         ← صفحة مشروعاتنا (المعرض التفاعلي، فلاتر التصنيف، الـ Lightbox)
├── project-details.html  ← صفحة تفاصيل المشروع (تقرأ ?id= من الرابط وتعرض المواصفات)
├── news.html             ← صفحة الأخبار والمركز الإعلامي
├── contact.html          ← صفحة اتصل بنا (نموذج المقايسة، ربط واتساب، خريطة جوجل)
├── 404.html              ← صفحة الخطأ المتناسقة مع هوية الموقع
├── css/
│   └── style.css         ← ملف التنسيقات المشترك بالكامل (ألوان، خطوط، هوية، تجاوب)
├── js/
│   ├── data.js           ← ملف البيانات المركزي (النصوص، المشروعات، الصور، الترجمة)
│   └── main.js           ← المنطق البرمجي (الهيدر، الفوتر، القوائم، السلايدر، الفلاتر)
├── images/               ← مجلد الصور المرفوعة المستخدمة في الموقع
└── README.md             ← دليل التوثيق والتشغيل والرفع
```

## ⚙️ 3) كيف تعدّل البيانات والنصوص من `js/data.js`

تم فصل محتوى الموقع بالكامل داخل ملف واحد بسيط هو `js/data.js`:

### أ) تعديل أرقام الهواتف والواتساب والعناوين:
ابحث عن كائن `SITE_CONFIG` في بداية `js/data.js`:
```javascript
const SITE_CONFIG = {
  companyNameAr: 'بناة مصر للإنشاءات والمقاولات',
  phone: '+20 2 2795 8800',           // رقم الهاتف الأرضي
  mobile: '+20 100 234 5678',         // رقم الموبايل
  whatsappNumber: '201002345678',     // رقم الواتساب بدون علامة +
  email: 'info@egyptbuilders.com',    // البريد الإلكتروني
  addressAr: 'عنوان شركتك هنا...',
  formspreeEndpoint: 'https://formspree.io/f/xvgzqgky' // رابط فورم سبري
};
```

### ب) تعديل الألوان الرسمية:
افتح ملف `css/style.css` وستجد الألوان في أول أسطر داخل `:root`:
```css
:root {
  --blue: #1B4F7A;        /* اللون الكحلي الأساسي للهيدر والعناوين */
  --gold: #B8935A;        /* اللون الذهبي للأزرار والرابط النشط */
  --terracotta: #B85C38;  /* اللون الطوبي للفاصل المنحني والحليات */
}
```

### ج) إضافة أو تعديل المشروعات:
في مصفوفة `PROJECTS_DATA` بملف `js/data.js`، يمكنك تعديل أي مشروع أو إضافة مشروع جديد بنفس البنية:
```javascript
{
  id: 'my-new-project',
  category: 'residential', // residential, commercial, industrial, infrastructure
  categoryNameAr: 'سكني',
  titleAr: 'اسم المشروع هنا',
  locationAr: 'الموقع',
  clientAr: 'اسم العميل',
  areaAr: '50,000 م²',
  year: '2025',
  image: IMAGES.project01,
  summaryAr: 'نبذة سريعة عن المشروع...'
}
```

## 🚀 4) طريقة رفع المشروع على GitHub وتفعيل GitHub Pages خطوة بخطوة

بما أن الموقع ثابت بالكامل (Pure HTML/CSS/JS) بدون أي بيئة بناء، يمكنك رفعه وتشغيله مجاناً في دقائق:

### الخطوة 1: إنشاء مستودع جديد (New Repository)
1. ادخل على حسابك في [GitHub](https://github.com).
2. اضغط على زر **New** لإنشاء مستودع جديد.
3. اكتب اسماً للمستودع (مثلاً: `egypt-builders`).
4. اختر **Public** ثم اضغط **Create repository**.

### الخطوة 2: رفع الملفات إلى GitHub
باستخدام Git على جهازك:
```bash
git init
git add .
git commit -m "الإصدار الأول لموقع بناة مصر"
git branch -M main
git remote add origin https://github.com/اسم-حسابك/egypt-builders.git
git push -u origin main
```
*(أو يمكنك سحب وإفلات الملفات مباشرة من متصفحك عبر زر **Upload files** في صفحة المستودع).*

### الخطوة 3: تفعيل GitHub Pages
1. ادخل على صفحة المستودع على GitHub، ثم اضغط على تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية على اليسار، اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - في خانة **Source**، اختر **Deploy from a branch**.
   - في خانة **Branch**، اختر `main` واجعل المجلد `/(root)`.
4. اضغط على زر **Save**.

### الخطوة 4: زيارة الموقع المباشر
خلال دقيقة أو دقيقتين ستظهر رسالة خضراء بالأعلى تحتوي على الرابط الرسمي لموقعك:
`https://username.github.io/egypt-builders/`
وسيعمل الموقع فوراً بكافة صفحاته وروابطه النسبية بسلاسة تامة.
